Standard Specification

FastWebMCP & Declarative AI Tools

FastWebMCP bridges web applications and AI agents by exposing tools through standard browser APIs: both imperatively via document.modelContext and declaratively via HTML forms.

FastWebMCP Documentation ↗ WebMCP Protocol Spec ↗

1. Declarative DOM Forms

Any web application can make its actions discoverable to AI agents simply by decorating standard HTML forms with toolname and tooldescription attributes: 

<!-- Declarative AI Tool in HTML -->
<form toolname="run_bash"
      tooldescription="Execute bash in in-memory sandbox">
  <input name="command" 
         toolparamdescription="Bash command string" />
  <button type="submit">Run</button>
</form>

WebMCP automatically scans the document, parses form fields as parameter schemas, and registers them into the agent tool registry.

2. Imperative JavaScript Bridge

For programmatic control, tools can be registered into the browser's global model context: 

// Imperative Tool Registration
document.modelContext.registerImperativeTool({
  name: "vfs_read",
  description: "Read file from virtual disk",
  inputSchema: {
    type: "object",
    properties: { path: { type: "string" } },
    required: ["path"]
  },
  handler: async ({ path }) => {
    return vfs.readFile(path);
  }
});

Conforms strictly to standard tool schema validation rules (regex: ^[A-Za-z0-9_.-]{1,128}$).

Getting Started

Integrate in Seconds

Embed an in-memory bash sandbox or WebMCP provider into any webpage or application.

1. Drop-in HTML Script Embed 
<!-- Include Terminal Container -->
<div id="terminal-container" style="height: 400px;"></div>

<!-- Load just-bash ES Module -->
<script type="module" src="https://mauricioperera.github.io/webmcp-just-bash/src/main.js"></script>
2. Programmatic Usage (ES Modules) 
import { VirtualFS } from './src/core/vfs.js';
import { BashRuntime } from './src/core/bash-runtime.js';

const vfs = new VirtualFS();
const bash = new BashRuntime(vfs);

// Execute pipelines directly:
const res = await bash.exec('echo "Hello World" | tr "a-z" "A-Z" > greeting.txt');
console.log(await vfs.readFile('/home/user/greeting.txt')); // "HELLO WORLD\n"
3. Clone and Run Locally 
# Clone repository
git clone https://github.com/MauricioPerera/webmcp-just-bash.git
cd webmcp-just-bash

# Run automated unit and stress test battery
npm test

# Serve statically
npx serve . -p 8080
